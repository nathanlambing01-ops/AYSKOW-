Structure du site :

- assets/hero.jpeg

Installation GitHub Pages :
1. Remplacer les anciens fichiers par tout le contenu de ce dossier.
2. Conserver le dossier assets à côté de index.html.
3. Vérifier que les noms des fichiers restent exactement identiques (minuscules).
4. Publier avec GitHub Pages.

Les images des classes et l'image du fond sont incluses dans le dossier assets afin d'éviter les images cassées.
